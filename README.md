
# Hangman Word Guessing Game

## Project Description
A console-based Hangman game developed using Python 3.

The player needs to guess a randomly selected hidden word within 6 incorrect attempts.

## Features
- Random word selection
- Maximum 6 incorrect attempts
- ASCII Hangman graphics
- Tracks guessed letters
- Prevents duplicate guesses
- Victory and Game Over messages

## Technologies Used
- Python 3
- Random module
- VS Code

## How to Run
1. Download the repository.
2. Open the project folder in VS Code.
3. Run:

python hangman.py
